# Bilinen Eksikler ve Sonraki Adımlar

Bu sürüm, üretime taşınabilir mobil uygulama temelini ve ana ticari akışları ekler. Aşağıdaki başlıklar store öncesi iş planı olarak tamamlanmalıdır:

- Teklif PDF şablonu web tarafındaki marka tasarımına göre genişletilecek.
- Tahsilat/dekont yükleme ekranı Supabase Storage policy doğrulaması sonrası açılacak.
- Rol bazlı yetki matrisi mevcut admin_users yapısıyla genişletilecek.
- Push notification gönderen backend job/cron endpointleri eklenecek.
- Offline senkronizasyon için çakışma çözüm ekranı detaylandırılacak.
- Ürün fotoğrafı çekme ve belge tarama akışları Storage bucket izinleriyle test edilecek.
- Rapor grafik ekranları satış verisine göre detaylandırılacak.
- E2E testler EAS development build üzerinde çalıştırılacak.
